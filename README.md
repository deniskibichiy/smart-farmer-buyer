# Smart-Farmer-Buyer
Smart Farmer-to-Buyer Produce Matching System — BSc Computer Science Capstone

The Smart Farmer-to-Buyer Management System is a software solution designed to connect farmers with potential buyers of agricultural produce.
Farmers can list available produce, including type, quantity, location, price, and availability date. Buyers will be able to specify the type and quantity of produce they require.
The system will analyse the available information and match farmers with suitable buyers based on relevant factors such as produce type, quantity, location, price, and availability.
The system is intended to improve market access for farmers, make it easier for buyers to find suitable suppliers, and reduce the likelihood of agricultural produce remaining unsold.
