# User Stories

## User Story 1

Farmer — Inventory and Pricing

As a Farmer, I want to easily upload crop photos, set custom prices, and define minimum bulk purchase quantities, so that buyers know exactly what I have for sale today and I can manage my profit margins effectively.

## User Story 2

Buyer — Marketplace Search

As a Buyer, I want to filter the marketplace by location radius, crop type, and price, so that I can quickly find the freshest, most affordable local ingredients near my neighborhood.

## User Story 3

Buyer — Order Tracking

As a Buyer, I want to view the real-time status of my active purchase, so that I know exactly when my produce is harvested, when it is out for delivery, and when it will arrive.
